# Зов Карачая · конный прокат «Олимп»

Сайт конного проекта в Кисловодске. Один файл `index.html` + папка `img/` с фотографиями.

## Концепция
Сайт устроен как фильм в главах: **I Зов → II Порода → III Тропы → IV Свет → V Ритуал → VI Люди → VII Форматы → VIII Тропа ждёт → Запись**.
Настроение — тишина высоты: ночь, ветер, первый свет над Минги-Тау. Сдержанно, без «этношоу».

## Визуальная система
- **Цвет:** Ночь Минги-Тау `#0a0d0b`, Сланец `#111613`, Кость `#ebe5d8`, Снег `#f6f2ea`, Пепел `#9ea195`, Латунь рассвета `#c5a26d`.
- **Шрифты:** Cormorant Garamond (заголовки, светлое начертание + курсив для акцентов) и Manrope (текст, разрядка заглавных подписей).
- **Изображения:** единый тёплый приглушённый грейд, плёночное зерно, крупные детали (грива, верёвочная уздечка, Эльбрус на горизонте).
- **Знак:** круг-солнце, хребет латунной линией, тропа.

## Движение и взаимодействия
- прелоадер с прорисовкой знака (только при первом заходе за сессию);
- первый кадр: медленный наезд камеры, буквы поднимаются из маски, свет следует за курсором;
- манифест проявляется словами по мере прокрутки;
- «Тропы» — горизонтальная киноплёнка, закреплённая на экране, с параллаксом внутри кадров;
- «Свет» — фон переходит от ночи к золотому часу, солнце поднимается при прокрутке;
- форматы — превью фотографии следует за курсором; фирменный курсор с подписью действия; магнитные кнопки;
- звук ветра (синтезируется в браузере, по умолчанию выключен);
- **Тулпар — говорящий конь-гид**: факты об истории Карачая, советы новичкам, подбор прогулки за два вопроса с переходом в запись, озвучка голосом.
- Всё движение отключается при системной настройке «уменьшить движение».

## Фотографии
Все снимки — из ваших фото, с единой цветокоррекцией. Чтобы заменить кадр, положите файл с тем же именем в `img/`.

| Файл | Где появится | Статус |
|---|---|---|
| `hero.jpg` | первый кадр | ✅ |
| `detail-mane.jpg`, `detail-bridle.jpg` | «Порода», карточки троп | ✅ |
| `route-2.jpg`, `story.jpg`, `route-4.jpg`, `frame-elbrus.jpg` | карточки троп | ✅ |
| `day.jpg` | финальный кадр | ✅ |

Рекомендуемая ширина — 1200–2000 px, JPG. Сильнее всего сайт усилят: рассвет/закат на тропе, группа всадников на хребте, портреты команды.
