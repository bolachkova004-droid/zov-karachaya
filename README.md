# Зов Карачая · конный прокат «Олимп»

Сайт конного проекта в Кисловодске.

## Что уже есть
- основные маршруты: Олимпийский парк, Малое Седло, Большое Седло;
- программы для новичков и опытных всадников;
- рассвет, золотой час и конный пикник;
- фотосессии и фотопрогулки;
- женские прогулки и конный девичник;
- предложение в горах;
- знакомство с карачаевской лошадью;
- туры выходного дня;
- форма записи, подготовленная под подключение Telegram-бота.
