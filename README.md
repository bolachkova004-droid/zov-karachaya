# Зов Карачая · конный прокат «Олимп»

Сайт конного проекта в Кисловодске. Один файл `index.html` + папка `img/` с фотографиями.

## Концепция
Сайт устроен как серия «слайдов» на угольном фоне (по референсу-презентации) с кинематографичным движением: **обложка → Зов → Порода → Тропы → Правда vs миф → Свет → Как проходит прогулка → Люди → Форматы → Тропа ждёт → Запись**.
Настроение — тишина высоты: ночь, ветер, первый свет над Минги-Тау. Сдержанно, без «этношоу».

## Визуальная система
- **Цвет:** Уголь `#1c1c1a`, Бумага `#ecebe6`, Шоколад `#5a3a2a`, Олива `#a7a23e`, Глина `#e6b2a2`, Хвоя `#3e4a35`.
- **Шрифт:** Inter Tight — плотный гротеск капсом для заголовков, спокойный текст. Акценты — наклонённые плашки-пилюли, рукописные петли-стрелки, подписи в углах слайдов.
- **Изображения:** единая цветокоррекция под палитру — небо уходит в приглушённый сланец, зелень в оливу, тени в тёплый уголь `#1c1c1a`, света в цвет бумаги `#f3efe6`; поверх — плёночное зерно.
- **Знак:** оливковый круг-солнце с силуэтом горы.
- **«Правда vs миф»:** игра из шести утверждений о лошадях и прогулках — снимает страхи новичков и ведёт к записи.

## Движение и взаимодействия
- прелоадер с прорисовкой знака (только при первом заходе за сессию);
- первый кадр: медленный наезд камеры, буквы поднимаются из маски, свет следует за курсором;
- манифест проявляется словами по мере прокрутки;
- «Тропы» — горизонтальная киноплёнка, закреплённая на экране, с параллаксом внутри кадров;
- «Свет» — фон переходит от ночи к золотому часу, солнце поднимается при прокрутке;
- форматы — превью фотографии следует за курсором; фирменный курсор с подписью действия; магнитные кнопки;
- звук ветра (синтезируется в браузере, по умолчанию выключен);
- **Тулпар — говорящий конь-гид**: факты об истории Карачая, советы новичкам, подбор прогулки за два вопроса с переходом в запись, озвучка голосом.
- Всё движение отключается при системной настройке «уменьшить движение».

## Фотографии
Все снимки — из ваших фото, с единой цветокоррекцией. Чтобы заменить кадр, положите файл с тем же именем в `img/`.

Каждая сцена встречается на сайте **один раз**. Снимки из RAW (`.dng`) выгружены с той ориентацией, которую записал телефон, без поворотов и отражений.

| Файл | Где на сайте |
|---|---|
| `hero.jpg` | обложка |
| `forest-pair.jpg` | «Порода» |
| `overhead.jpg` | тропа 01 «Первое знакомство» |
| `route-2.jpg` | тропа 02 «Олимпийская тропа» |
| `ears-hills.jpg` | тропа 03 «Первый горизонт» |
| `saddle-elbrus.jpg` | тропа 04 «Кавказ на ладони» |
| `day.jpg` | тропа 05 «Выше города» |
| `story.jpg` | тропа 06 «Свободный темп» |
| `sunrays.jpg` | «Свет» — фон, проявляется при прокрутке |
| `dog.jpg` | финальный кадр «Одного раза мало» |
| `girl-clouds.jpg` | «Форматы» — большое фото рядом со списком |
| `dog-pet.jpg` | «Запись» |

Новые фото прогоняйте через тот же грейд, тогда они лягут в общую гамму:

```
pip install pillow numpy
python3 tools/grade.py исходник.jpg img/имя.jpg 1600
```
(последнее число — ширина в пикселях; для RAW-снимков с телефона, лежащих «на боку», добавьте `-90`).

Рекомендуемая ширина — 1200–2000 px, JPG. Сильнее всего сайт усилят: рассвет/закат на тропе, группа всадников на хребте, портреты команды.
