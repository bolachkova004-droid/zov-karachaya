# Зов Карачая · конный прокат «Олимп»

Сайт конного проекта в Кисловодске. Один файл `index.html` + папка `img/` с фотографиями.

## Что есть на сайте
- первый экран с фото коня на фоне Эльбруса;
- «капсулы» с цифрами, легенда проекта, раздел о карачаевской породе;
- маршруты в виде «тропы», которая прорисовывается при прокрутке: Олимпийский парк, Малое и Большое Седло;
- рассвет, золотой час и конный пикник; фотосессии; команда; женские форматы и события;
- «День с карачаевской лошадью», туры выходного дня;
- форма записи, подготовленная под подключение Telegram-бота;
- **Тулпар — говорящий конь-гид**: рассказывает факты об истории Карачая и породе, даёт советы новичкам,
  подбирает прогулку за два вопроса и сразу открывает запись. Может говорить вслух (кнопка с динамиком).

## Фотографии
Достаточно положить файл с нужным именем в `img/` — сайт подхватит его сам, иначе покажет рисунок-заглушку.

| Файл | Где появится | Статус |
|---|---|---|
| `hero.jpg` | первый экран | ✅ есть |
| `story.jpg` | «Почему Зов Карачая» (арка) | ✅ есть |
| `route-2.jpg` | Олимпийская тропа | ✅ есть |
| `route-4.jpg` | Кавказ на ладони (Большое Седло) | ✅ есть |
| `day.jpg` | День с карачаевской лошадью | ✅ есть |
| `route-1.jpg`, `route-3.jpg`, `route-5.jpg`, `route-6.jpg` | остальные маршруты | можно добавить |
| `photo-1.jpg` … `photo-3.jpg` | карточки фотосессий | можно добавить |
| `team-1.jpg`, `team-2.jpg`, `team-3.jpg` | портреты команды (вертикальные) | нужны |

Рекомендуемая ширина — 1200–2000 px, формат JPG.
